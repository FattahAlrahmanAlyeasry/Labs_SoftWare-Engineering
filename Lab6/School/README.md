# نظام إدارة المدرسة المتطور

نظام شامل لإدارة المدارس والمؤسسات التعليمية مبني بتقنية Django مع أفضل الممارسات في هندسة البرمجيات.

## المميزات الرئيسية

### 🎓 إدارة الطلاب
- تسجيل وإدارة بيانات الطلاب
- تتبع الدرجات والمعدلات التراكمية
- إدارة الملفات والوثائق
- نظام البحث والتصفية المتقدم

### 👨‍🏫 إدارة المعلمين
- إدارة بيانات المعلمين والموظفين
- تتبع المؤهلات والخبرات
- إدارة الرواتب والحوافز
- تقارير الأداء

### 🏢 إدارة الأقسام
- تنظيم الأقسام الأكاديمية
- تعيين رؤساء الأقسام
- إحصائيات شاملة لكل قسم

### 🔐 نظام أمان متقدم
- مصادقة المستخدمين
- صلاحيات متدرجة
- حماية البيانات الحساسة
- تشفير كلمات المرور

### 📊 تقارير وإحصائيات
- لوحة تحكم تفاعلية
- تقارير مفصلة
- إحصائيات في الوقت الفعلي
- تصدير البيانات

### 🌐 واجهة برمجة التطبيقات (API)
- REST API كامل
- توثيق تفاعلي
- دعم التصفية والبحث
- استجابة JSON

## التقنيات المستخدمة

- **Backend**: Django 5.2.5
- **Database**: SQLite (قابل للتطوير لـ MySQL/PostgreSQL)
- **API**: Django REST Framework
- **Frontend**: HTML5, CSS3, JavaScript (بدون مكتبات خارجية)
- **UI**: تصميم مخصص متجاوب
- **Security**: Django Security Best Practices

## متطلبات النظام

- Python 3.8+
- Django 5.2.5
- Pillow (لمعالجة الصور)
- Django REST Framework
- Django Filter

## التثبيت والإعداد

### 1. استنساخ المشروع
```bash
git clone <repository-url>
cd School
```

### 2. إنشاء البيئة الافتراضية
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# أو
venv\Scripts\activate  # Windows
```

### 3. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 4. إعداد متغيرات البيئة
```bash
cp .env.example .env
# قم بتعديل ملف .env حسب احتياجاتك
```

### 5. إعداد قاعدة البيانات
```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. إنشاء مستخدم إداري
```bash
python manage.py createsuperuser
```

### 7. تشغيل الخادم
```bash
python manage.py runserver
```

الآن يمكنك الوصول للنظام عبر: http://127.0.0.1:8000

```
│   ├── models.py          # نماذج البيانات المحسنة
│   ├── views.py           # طبقة العرض المتقدمة

│   ├── admin.py           # واجهة الإدارة

├── Teacher/               # تطبيق المعلمين (للتوافق العكسي)
├── User/                  # تطبيق المستخدمين (للتوافق العكسي)
├── templates/             # قوالب HTML
│   └── core/             # قوالب التطبيق الرئيسي
├── static/               # الملفات الثابتة
│   ├── css/             # ملفات CSS
│   └── js/              # ملفات JavaScript
├── media/                # ملفات المستخدمين
├── logs/                 # ملفات السجلات
└── manage.py             # أداة إدارة Django
```

## الاستخدام

### لوحة التحكم
- الوصول عبر: `/`
- عرض الإحصائيات العامة
- روابط سريعة للوظائف الرئيسية

### إدارة الطلاب
- قائمة الطلاب: `/students/`
- إضافة طالب: `/students/create/`
- تفاصيل الطالب: `/students/<id>/`

### إدارة المعلمين
- قائمة المعلمين: `/teachers/`
- إضافة معلم: `/teachers/create/`
- تفاصيل المعلم: `/teachers/<id>/`

### واجهة برمجة التطبيقات
- نقطة البداية: `/api/`
- الطلاب: `/api/students/`
- المعلمين: `/api/teachers/`
- الأقسام: `/api/departments/`

## النشر في الإنتاج

### إعدادات الإنتاج
1. تعيين `DEBUG = False`
2. إعداد قاعدة بيانات إنتاج
3. إعداد خادم الويب (Apache/Nginx)
4. تأمين المتغيرات الحساسة

### متغيرات البيئة المطلوبة
```bash
DJANGO_SECRET_KEY=your-production-secret-key
DJANGO_DEBUG=False
DJANGO_ALLOWED_HOSTS=yourdomain.com
DATABASE_URL=your-production-database-url
```
